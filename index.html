Projeto em Destaque

GitHub

Garagem Digital

Aplicação web full stack para catalogar projetos automotivos, reunir garagens pessoais, perfis, interações sociais e equipes.

Projeto autoral desenvolvido com Python, Flask, MySQL, HTML, CSS e JavaScript Vanilla. A aplicação começou como um CRUD de veículos e evoluiu para a base de uma plataforma social automotiva, com autenticação, hash de senhas, permissões por usuário, upload de imagens, perfis, seguidores, curtidas, comentários, garagem pessoal e recursos iniciais para equipes. O desenvolvimento segue um fluxo organizado com Git/GitHub, issues, branches pequenas e pull requests.

Destaques do Sistema

  • Cadastro e login de usuários
  • Feed geral e garagem pessoal
  • Controle de propriedade por usuário
  • Curtidas e comentários
  • Perfis, avatar, bio e seguidores
  • Modal com visualização detalhada
  • Upload de imagens e avatars
  • API REST com Flask e MySQL
