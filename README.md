## Tecnologias do portfólio

- HTML5 semântico com progressive enhancement (publicável sem etapa de build no GitHub Pages)
- CSS modular responsivo (identidade visual do Garona isolada em `.garona-showcase`, spotlight nos cards e suporte a `prefers-reduced-motion`)
- JavaScript vanilla com `DotGrid` em Canvas 2D no Hero, janela interativa de código (`Flutter · FastAPI · PostgreSQL`), GSAP/ScrollTrigger vendored localmente (`assets/vendor/`), menu mobile acessível e cópia de e-mail com status acessível
- Dados estruturados Schema.org, metadados Open Graph / Twitter Card e fontes empacotadas localmente com licenças OFL (`DM Sans`, `Space Grotesk`, `Barlow Condensed`, `Manrope`)

## Executar localmente

O projeto é estático. Clone o repositório e sirva os arquivos via servidor HTTP local (recomendado para suportar cópia para a área de transferência via contexto seguro):

```bash
git clone https://github.com/raullferreiraa/raullferreiraa.github.io.git
cd raullferreiraa.github.io
python -m http.server 8765
```
